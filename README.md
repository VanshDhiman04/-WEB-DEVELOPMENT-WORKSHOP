# 🌐 Web Development Workshop

A collection of web development experiments and projects created as part of the **BCS353 Web Designing Workshop**.

This repository demonstrates my learning and practical implementation of HTML, CSS, and JavaScript through hands-on web development exercises.

## 🚀 Featured Project: Online Bookstore

A multi-page bookstore website designed to present engineering books and provide a simple browsing experience.

🔗 **[Live Demo](https://web-development-workshop-mmckxrrpn-zero-bug2.vercel.app/)**

### ✨ Features

- **Home Page:** Welcome section with background images and bookstore introduction.
- **Navigation:** Header navigation for Home, Login, Registration, Catalogue, and Cart.
- **Department Sidebar:** Links for CSE, ECE, EEE, and Civil Engineering.
- **Login and Registration:** Forms for user input.
- **Book Catalogue:** Displays book details, authors, publishers, prices, and cover images.
- **Shopping Cart:** Interface for viewing selected books.
- **Responsive Styling:** CSS styling for a clean and consistent interface.
- **Interactive Elements:** Hover effects and JavaScript-based functionality where implemented.
